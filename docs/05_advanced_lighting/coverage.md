## 数值与失败路径旁证

以下使用相同源码的隔离副本插入诊断或故障，正式示例不增加测试专用运行参数：

| 检查 | 条件与结果 |
| --- | --- |
| 必需 uniform | 将 SSAO 初始化查询名称 radius 改为 missing_radius：打印缺失名称，退出码 1，未继续绘制。 |
| 窗口尺寸变化 | Gamma 硬件编码、泛光、SSAO 三个隔离程序在第一帧后调用 GLFW 改为 640×360；第三帧截图均为 640×360，无 stderr 或 GL 错误。 |
| HDR 浮点范围 | 第一次隧道绘制后，以 GL_RGBA/GL_FLOAT 从 HDR 附件读回；全部数值有限，最大值约 18.3594，确认中间存储未钳在 1。 |
| AO 范围 | 模糊前以 GL_RED/GL_FLOAT 读回 R16F；全部值有限且位于 [0,1]，当前场景约为 0.395752–1。 |
| 命令行失败 | 每个程序分别拒绝 --frames 0、--mode -1、缺少 --frames 的 --capture，共 30 次预期非零退出检查。 |
| 范围错误可观察性 | 阴影模式 4/10 使用同一正交范围与视角；图像差异确认遗漏远平面检查会产生伪阴影，不只存在两个编号。 |

这些是本机集成检查，不是性能基准，也不取代其他分辨率、显示系统与完整交互验证。隔离程序从其临时工作目录运行，资源仍由编译期资源根解析。

## 本次技术修订

- Blinn-Phong：限定同半球及半程零向量前提，高光指数倍率为经验；不把经验模型表述为物理保证。
- 颜色：sRGB 是分段曲线，2.2 仅近似；区分输入解码、输出编码与参数贴图，使用明确 sRGB 附件验证硬件路径。
- 阴影：纯深度 FBO 可以完整；坐标映射不等于裁剪；PCF 平均比较结果，textureSize 返回整数向量；正面剔除有适用范围。
- 点阴影：每次 EmitVertex 前重新设置 gl_Layer 和其他输出；64次三维采样数量与径向距离度量明确。
- 切线：T 用线性变换、N 用逆转置；cross(N,T) 配合手性；transpose 等于 inverse 需要正交基。
- 视差：UV 位移不等于顶点位移，明确高度/深度及搜索方向；插值保护分母，保留掠射和轮廓限制。
- HDR/泛光：浮点有限范围，色调映射有损；九采样核与十遍/五组分离模糊的计数纠正；初始输入必须为亮区而非空目标。
- 延迟：不宣称分支优化必然无效或 MSAA 不可能；球体策略与复杂度限制写明，深度复制选同格式目标。
- SSAO：统一观察空间和深度符号，smoothstep 是软范围权重，只调制环境项，明确屏幕空间缺失信息。
