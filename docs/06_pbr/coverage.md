## 实测与边界

- MinGW GCC Debug configure/build 通过；GTX 1660 23/23 模式各运行 3 帧并保存末帧，未出现 stderr 或 OpenGL 错误。全部模式组成总览图检查；材质、模型、双环境、卷积层级、LUT 及错误对照均有实际输出。
- 恒定环境 C=(0.25,0.5,1)：六面 E/π 读回与 C 的最大差为 0（半精度存储后，本次采样设置），包含所有朝向；此结果不代表任意 HDR 环境积分均精确。
- 两套环境：所有环境 mip、六面 E/π、五层预过滤数据和 LUT 读回均有限且非负；HDR 环境最大值 16.125，证明未被钳在 1。LUT 值在检查范围 [0,1.1] 内。
- LUT：六个跨 N·V/粗糙度的像素与相同 1024 点 GGX 估计的双精度 CPU 参考比较，最大绝对误差小于 0.000484。检查系数数值，不以颜色截图代替数学对应。
- 失败路径隔离副本：缺必需 uniform、缺 HDR、无有效深度存储的 FBO 均返回非零且打印具体诊断；常规程序不增加测试专用运行选项。
- GLAD 调试包装：新增保存错误标记的 post 回调，使用原始 glGetError 指针避免递归。隔离程序故意调用 glEnable(0xFFFFFFFF)，打印 glEnable/1280 并返回 1，确认错误即使被查询消费也不会漏报退出失败。
- 命令行：三个目标分别拒绝 --frames 0、--mode -1、未指定 --frames 的 --capture，共 9 次预期非零退出。
- 过滤对照：当前环境下模式 8/11 与 0/10 的 RGB 字节平均绝对差分别约 0.163 与 0.026，最大差为 5 与 3。路径存在可测差异，但这组环境的伪像较轻，不据此声称所有环境都有显著接缝或亮点。
- 尺寸变化隔离副本：漫反射与镜面示例在第一帧后改为 640×360，第三帧截图均为该尺寸且无错误；从临时目录运行仍可解析仓库资源。
- 未验证：其他 preset/显卡实际运行、完整键鼠与最小化/高 DPI 交互、色彩管理、GPU 性能、局部探针与视差校正、缓存序列化、多重散射能量补偿。离线工具与探针内容按上游作为后续讨论保留，不声称已经实现。
